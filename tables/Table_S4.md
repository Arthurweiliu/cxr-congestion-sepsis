# Table S4. Four-group estimates before and after adjustment for continuous fluid balance

Multiple imputation (m = 20, seed 20261023); n = 3,963, deaths = 832. Same imputation set and covariates as Table 2.

| Variable | OR (95% CI), base model | OR (95% CI), + continuous balance |
|---|---|---|
| Group B (no congestion / balance >0) | 1.43 (1.05–1.96) | 0.90 (0.64–1.27) |
| Group C (congestion / balance ≤0) | 1.59 (1.08–2.33) | 1.61 (1.10–2.36) |
| Group D (congestion / balance >0) | 2.44 (1.76–3.39) | 1.64 (1.16–2.33) |
| 72-h balance, per 10 mL/kg | — | 1.06 (1.04–1.07) |

Covariates as in Table 2: age, sex, SOFA, lactate, invasive ventilation, vasopressors, heart failure, chronic kidney disease.

**Note.** The second column adds the continuous 72-h balance to the model in Table 2. It was fitted after the primary analysis, is not pre-specified, and is less powered than the primary contrast; group C was numerically unchanged, group B moved to the null and group D attenuated. A repeat analysis that additionally included the binary congestion term in the imputation model gave the same estimate for group C (1.61, 1.10–2.36).
