| Variable | OR (95% CI), base model | OR (95% CI), + continuous balance |

| Group D (congestion / balance >0) | 3.25 (2.38–4.44) | 2.09 (1.49–2.93) |

Covariates as in Table 2: age, sex, SOFA, lactate, invasive ventilation, vasopressors, heart failure, chronic kidney disease.

**Note.** The second column adds the continuous 72-h balance to the model in Table 2. Group B moves to the null and group D attenuates, whereas the estimate for group C is unchanged; that comparison is secondary and less powered than the primary contrast.
