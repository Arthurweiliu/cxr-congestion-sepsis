Multiple imputation (m = 20); n = 3,963, deaths = 832. Same imputation set and covariates as Table 2. Balance is film-anchored (72 h after the index film).

| Variable | OR (95% CI), base model | OR (95% CI), + continuous balance |

| Group D (congestion / balance >0) | 3.31 (2.42–4.52) | 2.09 (1.49–2.92) |
| 72-h balance, per 10 mL/kg | — | 1.06 (1.05–1.08) |

Covariates as in Table 2: age, sex, SOFA, lactate, invasive ventilation, vasopressors, heart failure, chronic kidney disease.

**Note.** The second column adds the continuous 72-h balance to the model in Table 2. Group B moves to the null and group D attenuates, whereas the estimate for group C is unchanged; the comparison for group C was not pre-specified and is less powered than the primary contrast.
