## 1. 题目

**Radiographic pulmonary congestion and measured fluid balance in sepsis: discordance and independent association with 30-day mortality**

---

## 2. 背景与缺口（重写）

### 2.1 已知

- 累积液体平衡与脓毒症不良结局相关，但效应量小、易受休克严重度混杂（本项目已实测：校正乳酸后效应进一步减弱）。
- ICU 中评估"淤血"至少有三种手段：临床体征、累积液体平衡、影像（超声/胸片）。三者关系不清。

### 2.2 反面证据（v1.0 遗漏，必须正面处理）

| 研究 | 设计 | 结论 | 对本研究的含义 |
|---|---|---|---|
| **Mund 2024**（*J Clin Med Res* 16:302-309，PMID 39027814） | 脓毒症 AKI，n=102，单中心回顾 | 复合定义的心肺淤血（临床+影像+超声+化验）患病率 **78.4%**，**与院内死亡、RRT、肾功能恢复均无关** | 直接反面证据。但样本小、未报告多变量校正、仅 AKI 亚组、暴露为复合定义；且 78.4% 的患病率提示复合定义阈值过宽（近八成被判为"心肺淤血"），本身削弱其阴性结论的说服力 |
| **INCIVEX 2026**（*Anaesthesiol Intensive Ther* 58:59-65，PMID 41879150） | ICU ≥72h，n=50，横断面 | **累积液体平衡与临床及超声参数均无相关** | 支持"测量不一致"，但同时削弱液体平衡作为淤血度量的地位 |

### 2.3 缺口（精确表述）

> 影像学肺淤血与累积液体平衡的**一致性从未在大样本中被系统量化**；两项小型研究（n=102、n=50）提示淤血与预后无关或各测量手段互不相关，但均未在足够样本、统一暴露定义与休克严重度校正下检验。**影像淤血是否在液体平衡之外携带独立预后信息，目前证据互相矛盾且功效不足。**

### 2.4 假设

- H1（一致性）：影像淤血与 72h 液体平衡的一致性低（预期 kappa < 0.2）
- H2（独立关联）：校正液体平衡与乳酸后，影像淤血仍与 30 天死亡独立相关（预期 OR 1.3–1.6）
- H3（增量）：影像淤血的预测增量有限（预期 ΔAUC < 0.02）

**H3 是预设的"允许为负"的假设**——若增量确实很小，本研究仍以"大样本确认无增量"为结论发表。

## 6. 暴露

### 6.1 影像淤血（主定义）

**报告匹配**：`charttime ∈ [study_ts − 2h, +2h]`，文本含 `chest|thorax` 且不含 `computed tomography|CT HEAD|CT CHEST|CT ABDOMEN|MRI`；同 study 多份取时间最近者。

**分类**：

| 类别 | 规则 |
|---|---|
| `pos_explicit` | IMPRESSION 段出现 `edema/oedema` 且无否定修饰 |
| `neg_explicit` | `no/without/absent/clear of/resolved/negative for` + 60 字内 + `edema/oedema` |
| `clear_lungs` | `clear lungs` / `no consolidation` / `no pleural effusion` / `no acute pulmonary` / `unremarkable` |
| `unknown` | 以上均不满足 |

**合并规则（v1.3 修订：hybrid 为主定义）**：

```
优先级 1（IMPRESSION）：pos_explicit -> 阳性；neg_explicit / clear_lungs -> 阴性
优先级 2（IMPRESSION 未描述肺时回落 FINDINGS）：
    FINDINGS 提及 edema -> 阳性；FINDINGS 明确否定/双肺清晰 -> 阴性
优先级 3（仍不确定）：chexpert.edema = 1 -> 阳性；否则 unknown -> 排除
```

**硬约束**：文本明确阴性时，`chexpert.edema = 1` 不得翻转。

**修订理由（W1 实测）**：严格 IMPRESSION-only 只能分类 3,019 例，因大量 IMPRESSION 只写管路位置而不描述肺；hybrid 可分类 4,576 例，且 hybrid 与严格版在两者均有值时仅 14 例判定不同——**差异几乎全部是覆盖率，而非判定分歧**。严格版作为 S12 完整报告。

**披露**：该修订在组间粗死亡率已被观察后做出，但决策依据是覆盖率（1,557 例样本量差异），非效应量；两版均全文报告，审稿人可自行判断。

### 6.2 敏感性定义 S1
FINDINGS 或 IMPRESSION 任一处提及 edema（未被否定）即阳性。

### 6.3 液体平衡（72h）

```
FB72 = Σ inputevents.amount [ml, status<>'Rewritten', starttime ∈ [intime, intime+72h)]
     − Σ outputevents.value [ml, charttime ∈ [intime, intime+72h)]
FB72_mlkg = FB72 / weight_admit
```

**缺失处理（更正与澄清）**：入量或出量整侧缺失 → 计算为 NULL → **排除**（非补零）。实测因此排除 224 例（4,576 → 4,352）。

**新增质量标记（S9 操作定义，已写死）**：

```
output_complete = 1  当且仅当 72h 总出量 ≥ 0.3 mL/kg/h × 72h 且至少存在 1 条 outputevents 记录
```

- 选择**总量下限**而非"输出类别数"：类别完整性在数据中无法直接判定，而总量异常偏低是记录不全的可观测代理
- S9 的处理是**排除** `output_complete = 0` 者，**不做任何下限校正**——校正需引入未经本数据验证的假设（如固定不显性失水），会把偏倚从一处挪到另一处
- S9 必须同时报告排除前后的 FB 分布（中位数、IQR、正平衡比例）

**按 `memory/方法学规则-液体类暴露.md` 执行 R1–R4。**

## 7. 结局

| 层级 | 结局 | 说明 |
|---|---|---|
| 主要 | 30 天全因死亡 | `deathtime ≤ intime+30d` 或 `dod ≤ date(intime+30d)` |
| **验证性次要** | 院内死亡 | 不依赖 `dod` 链接完整性；用于评估结局错分对主估计的影响 |
| 次要 | 90 天死亡、无通气天数、ICU LOS | — |

**层级声明（修订）**：**30 天死亡是唯一主要结局**。院内死亡是**预设的验证性次要结局**，其作用是评估 `dod` 链接不完整所致的结局错分对主估计的影响，而非第二个主要结局。两者结论不一致时，正文报告不一致本身并降级结论强度，**不以任一者替换另一者**。

`dod` 来自州生命统计链接，院外死亡存在已知漏报 → 30 天死亡可能被低估。

**28 天 vs 30 天的选择（W1 实测依据）**：早期队列（N=4,352）中 28 天死亡 909 例、30 天 932 例，差值仅 23 例（占死亡数 2.5%）。最终队列（N=3,963）30 天死亡 832 例，90 天死亡 1,089 例。因此 28 与 30 天的选择对推断无实质影响。**经与研究者确认：保留 30 天为唯一主要结局，不另设 28 天敏感性分析**（避免无信息的重复分析）；90 天按原计划作为次要结局且与主要结局同等篇幅报告。

## 9. 统计分析计划

### 9.1 描述
连续变量按分布报均数±SD 或中位数(IQR)；分类变量 n(%)；按四组报基线 + SMD。另单列 `unknown` 组基线（新增）。

### 9.2 一致性（Q1）— 已删除 Bland-Altman

Bland-Altman 要求两种方法在同一连续尺度测量同一量；本暴露一端为二分类、另一端为连续值，**不适用**。替代方案：

1. 2×2 表 + 各格患病率 + 死亡率热图
2. `FB72_mlkg` 在淤血阳性/阴性组的分布（小提琴图 + 中位数差 + bootstrap CI）
3. 按淤血严重度（mild/moderate/severe，文本关键词，**仅描述性**）分层的 FB 分布
4. **Cohen's kappa 为主**；PABAK 仅附录，并注明其度量的是"校正患病率后的一致性"，与 kappa 不可互换解释

### 9.3 主模型（Q2）

```
death30 ~ 四组(A/B/C/D) + 年龄 + 性别 + SOFA + 乳酸 + 通气 + 升压药 + 心衰 + CKD + CCI
```

- **主分析为四组整体**：以 A 为参照的三个哑变量（B、C、D）的**联合 Wald 检验**（H0: OR_B = OR_C = OR_D = 1，3 df）；同时报告**似然比检验**作为敏感性（稀疏格时 Wald 可能不稳）
- 主表同时给出：整体 p 值 + 以 A 为参照的三个 OR（95% CI）
- 预设关键对比：C vs A，标注为"**功效受限的预设对比**"，不作为唯一推断焦点
- 连续模型：`death30 ~ 淤血 + FB10 + 淤血×FB10 + 协变量`

**交互项来源披露（强制写入 Methods）**：

> 连续模型中的淤血 × FB 交互项系在 pilot 分析中首先观察到（OR 0.988, 95% CI 0.979–0.997, p=0.009），本 protocol 将其列为**探索性分析**并预设仅作描述性报告、不作因果解释；该发现需在独立样本中验证。

因此该交互项**不得**被称为"预设假设"，正文只能表述为 `exploratory, hypothesis-generating`。

### 9.4 预测增量（Q3）— 解释层级已明确

| 指标 | 地位 | 规则 |
|---|---|---|
| ΔAUC | **主判据** | < 0.01 → 正文只能写 "did not meaningfully improve discrimination" |
| NRI / IDI | 辅助 | 若 ΔAUC 极小但 NRI/IDI 有信号，讨论中可写 "may improve risk reclassification, though discrimination was unchanged"，**不得**写 "improved prediction" |
| 决策曲线 | 辅助 | 净获益差 < 0.01 视为无临床意义 |

| **S12** | **严格 IMPRESSION-only 定义（N=3,019）** |

### 9.6 缺失数据与预设决策规则

- 乳酸缺失：多重插补（m=20，含结局与协变量）；完整病例为 S8
- **S8 决策规则（新增）**：若插补集与完整病例的 C vs A OR 方向一致但幅度差 >20%，以插补集为主分析并报告差异；若**方向相反**，以插补集为主分析，并在局限性中明确报告该不一致，**不对任一结果作因果解释**。

### 9.7 多重比较
四组整体为单一检验；C vs A 为唯一预设关键对比；其余对比用 BH-FDR。

### 9.8 亚组（探索性）
心衰史、CKD、通气、SOFA 三分位。交互 p 仅描述，不作结论。

## 10. 偏倚控制

### 10.1 适应证偏倚
报告"拍片 vs 未拍片"基线差异；S7 逆概率选择加权。

### 10.2 暴露测量误差（新增）

胸片对肺血管外水增加不敏感，与 PAWP/EVLW 相关性有限；脓毒症肺水肿常为通透性水肿，而 CheXpert 与放射科报告的"edema"判读更贴近心源性模式。因此：

- **预期为非差异性错分**（假阴性为主），效应方向为**趋向零** → 任何阳性关联都是保守估计
- **组 C 的解释边界（强制）**：组 C 只能被解释为"**报告提及 edema 而 72h 液体平衡未显示正平衡**"，**不得**等同于"液体确实在肺内"。它无法区分"胸片真阳性"与"液体在肺外"
- `unknown` 组（约 30%，死亡率 23.6%，介于阴性与阳性之间）单独描述，S2/S10 处理
- RALE 评分：**当前不可行**（本地无 DICOM 图像；MIMIC-CXR-JPG 未下载），列为未来方向，不在本研究范围

### 10.3 其他
不死时间 → S3；心源性水肿 → S4；单中心 → 讨论中不作外推。

## 12. 样本量与可检测效应（修订）

| 阶段 | n |
|---|---:|
| Sepsis-3 首次住院、成人 | 25,596 |
| ±24h 有胸片 | 7,050 |
| 匹配到胸片报告 | 6,595 |
| 可分类 | 4,576 |
| 液体平衡可计算 | 4,352 |
| 清洗 + 时间锚定后 | **3,963**，死亡 **832（21.0%）** |

预期四格（探索性计数）：A 519（死亡 11.8%）、B 2,481（18.8%）、C 506（18.6%）、D 1,071（31.1%）。

- 整体暴露（淤血 34.5%）可检测 OR ≈ **1.20**（80% 功效，α=0.05）
- 与 Mund 等的比较：样本量约 **39 倍**（3,963 vs 102），但**人群不完全可比**——Mund 限于脓毒症 AKI 亚组，本研究为全脓毒症队列。正文必须同时写出两点，不得只比样本量
- **C vs A 功效受限**：按 506 vs 519、事件约 94 vs 61，可检测 OR ≈ **1.6**；考虑暴露错分后实际更高
- **因此主分析设为四组整体 + 连续交互模型，C vs A 仅作预设关键对比，不单独承担主要结论**

**预期描述性发现（新增）**：淤血阳性者中约 2/3 处于正液体平衡（1,071/1,577 = 67.9%）——即"影像淤血多数伴随正平衡"，但仍有 32% 相反。
